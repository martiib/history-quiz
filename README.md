# History Quiz

A command-line history quiz application built with Python.

This project was originally developed after completing a Python course and later improved as part of my ongoing learning and portfolio development. The aim was to strengthen core Python skills while improving code structure, readability, and maintainability.

The application allows users to answer multiple-choice history questions in the terminal. At the end of the quiz, it calculates the final score, provides performance feedback, and saves results to a CSV file for further analysis.

Key improvements in the updated version:

* Refactored into modular and reusable functions
* Improved code structure and readability
* Added type hints and docstrings
* Randomized question order
* Input validation for better user experience
* Score calculation with percentage results
* Enhanced terminal output using Colorama
* ASCII art feedback using PyFiglet
* CSV export of quiz results
* Cleaner project organization

Technologies used:

* Python 3.x
* CSV module
* Random module
* Colorama
* PyFiglet

This project demonstrates skills in:

* Python fundamentals and data structures
* Functional and modular programming
* File handling and data export
* User input validation
* Writing clean, maintainable code

To run the project, install the required dependencies and execute the Python file in the terminal.
